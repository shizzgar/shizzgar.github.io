3D Coder

О модели ↗

Текстовая модель — около 2,7 ГБ. Для первой картинки нужны ещё 676 МБ. Файлы могут сохраняться в браузере. При доступном WebGPU движок запрашивает перенос слоёв на GPU, иначе пробует CPU.

Диагностика

Свои файлы модели

Выбери один GGUF-файл до 2 ГиБ или все части одновременно. Большой файл сначала раздели через llama-gguf-split. Для картинок нужен отдельный mmproj.

Файлы остаются на устройстве. После перезагрузки страницы их может потребоваться выбрать снова. Движок и 3D-библиотека загружаются с внешних CDN.

Скачать модель на компьютер

ZIP содержит все части GGUF и компонент для картинок: около 3,4 ГБ загрузки. Для кэша и архива может потребоваться около 7 ГБ на диске. Распакуй ZIP перед выбором файлов в Forma.

Сохранение большого ZIP напрямую требует совместимого браузера. Докачка зависит от браузера, источника и сети.

Модель Q4_K_M · 2,71 ГБ ↓Для картинок (mmproj) · 676 МБ ↓

Целый файл модели подойдёт для совместимых программ. Для Forma файл больше 2 ГиБ сначала раздели через llama-gguf-split. Для текста mmproj не нужен.

Доступ к Hugging Face зависит от сети. Есть каталог Hologram ↗; доступность из РФ не проверена.

Токен Hugging Face

Токен остаётся в этой вкладке и отправляется только на huggingface.co. Ускорение не гарантировано. Отдельные прямые ссылки токен не используют.

Chrome на Linux и GPU

Включи аппаратное ускорение и нажми «Проверить WebGPU». Для движка нужны адаптер и shader-f16 в окне и тестовом worker. Это не подтверждает работу самой модели.

  1. Сохрани работу и полностью выйди из Chrome, включая фоновые процессы. Иначе новые параметры могут не примениться.
  2. Проверь тип сессии в терминале:
    printf 'Session: %s\nWayland: %s\n' "$XDG_SESSION_TYPE" "$WAYLAND_DISPLAY"
    Для сессии wayland с доступным Wayland display:
    google-chrome-stable --ozone-platform=wayland
    Для X11 или без Wayland display:
    google-chrome-stable
  3. Проверь WebGPU в Forma и на chrome://gpu, командную строку — на chrome://version. Во время генерации смотри буферы весов WebGPU в трассе.
Экспериментальные параметры NVIDIA

Эти параметры обходят ограничения и могут вызвать нестабильность. В одной из версий Dawn shader-f16 на Vulkan/NVIDIA штатно включается с драйвером 615.71. Принудительное включение на старом драйвере может вызывать ошибки.

Wayland:
google-chrome-stable --ozone-platform=wayland --enable-features=Vulkan --enable-unsafe-webgpu --enable-dawn-features=vulkan_enable_f16_on_nvidia
X11 с OpenGL для ANGLE:
google-chrome-stable --ozone-platform=x11 --use-angle=gl --enable-features=Vulkan --enable-unsafe-webgpu --enable-dawn-features=vulkan_enable_f16_on_nvidia

Для возврата к обычному запуску выйди из Chrome и запусти без флагов. WebGPU и WebGL могут работать по-разному; свободная VRAM недоступна. Диагностика Chrome ↗
