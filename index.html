Для начала работы с текстом — около 2,7 ГБ. Для первой картинки догрузим ещё 676 МБ и перезапустим модель. Браузер может сохранить файлы для следующих запусков. Нужен WebGPU; совместимость проверяется.

Скачать файлы на компьютер

Скачай файлы отдельно из Hugging Face. Они сохраняются на компьютер и не загружаются в Forma автоматически. Ход скачивания смотри в загрузках браузера.

Модель Q4_K_M · 2,71 ГБ ↓ Для картинок (mmproj) · 676 МБ ↓

Файл модели целиком подойдёт для других совместимых программ. Чтобы загрузить его в Forma, сначала раздели его на части не больше 2 ГиБ через llama-gguf-split. Для генерации только по тексту mmproj не нужен.

Доступ к Hugging Face зависит от твоей сети. Есть сторонний каталог Hologram ↗; его доступность и загрузка из РФ не проверены.

Свои файлы модели

Выбери один GGUF-файл до 2 ГиБ или все части модели одновременно. Большой файл сначала нужно разделить через llama-gguf-split. Для картинок добавь отдельный файл mmproj.

Файлы останутся на устройстве; после перезагрузки страницы их нужно выбрать снова. Движок и предпросмотр всё ещё загружаются с внешних CDN.
