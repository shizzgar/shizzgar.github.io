Настройки модели и диагностика
Токен Hugging Face (необязательно)

Для загрузки в Forma и комплекта ZIP: токен остаётся в этой вкладке и отправляется только на huggingface.co. Ускорение не гарантировано. Отдельные прямые ссылки токен не используют.

Chrome на Linux: запуск модели на GPU

Сначала обнови Chrome и драйвер видеокарты, включи аппаратное ускорение в настройках Chrome и нажми выше «Проверить WebGPU». Для текущего движка нужны доступный адаптер и shader-f16; обрати внимание на результаты окна и тестового worker. Тестовый worker не является worker модели и не подтверждает её работу. Chrome 155–156 поддерживает shader-f16 на Linux с NVIDIA при совместимом драйвере; доступность зависит от системы.

  1. Чтобы запустить Chrome с обычным профилем, сохрани работу и полностью выйди из всех окон и фоновых процессов Chrome через меню. Иначе команда может открыть вкладку в уже работающем процессе, а новые параметры не применятся.
  2. Проверь тип сессии в терминале:
    printf 'Сессия: %s\nWayland: %s\n' "$XDG_SESSION_TYPE" "$WAYLAND_DISPLAY"
    Если указана сессия wayland и задан Wayland display, запусти Chrome с обычным профилем:
    google-chrome-stable --ozone-platform=wayland
    Для X11 или если Wayland display не задан, используй:
    google-chrome-stable
  3. Открой Forma и нажми «Проверить WebGPU». Введи chrome://gpu в адресной строке и проверь WebGPU; в chrome://version можно увидеть командную строку запущенного процесса.
  4. Загрузи модель и проверь в «Устройство и параметры» именно буферы весов WebGPU. Наличие адаптера само по себе не подтверждает, что движок загрузил модель на GPU.
Если shader-f16 всё ещё недоступен: эксперимент

Эти экспериментальные параметры обходят некоторые ограничения WebGPU и могут снизить защиту или вызвать нестабильность. Например, в одной из версий Dawn для Vulkan на NVIDIA shader-f16 штатно включается с драйвером 615.71; принудительное включение на старом драйвере может приводить к ошибкам, а поведение зависит от версии Chrome. Они не гарантируют работу GPU. Сначала снова полностью выйди из Chrome. Для диагностики NVIDIA Linux можно запустить:

Для Wayland-сессии:

google-chrome-stable --ozone-platform=wayland --enable-features=Vulkan --enable-unsafe-webgpu --enable-dawn-features=vulkan_enable_f16_on_nvidia

Для X11 можно отдельно запросить OpenGL для ANGLE и Vulkan для движка:

google-chrome-stable --ozone-platform=x11 --use-angle=gl --enable-features=Vulkan --enable-unsafe-webgpu --enable-dawn-features=vulkan_enable_f16_on_nvidia

Вариант X11 с ANGLE/OpenGL может помочь, если WebGL не запускается через ANGLE/Vulkan. Эти флаги запрашивают Vulkan и принудительно включают поддержку f16 на NVIDIA; драйвер и сборка Chrome всё равно могут не поддерживать этот режим. Затем проверь параметры в chrome://version, нажми «Проверить WebGPU», проверь буферы модели во время генерации и дождись проверки сцены. Для возврата к обычному запуску полностью выйди из Chrome и открой его без этих параметров.

WebGPU и WebGL могут работать по-разному: успешный запуск модели не гарантирует отрисовку сцены. Браузер не показывает доступный объём VRAM. Подробнее: диагностика WebGPU в Chrome ↗.

Скачать файлы на компьютер

Кнопка «Скачать комплект ZIP» сохраняет готовые части GGUF и компонент для картинок одним архивом. Потребуется скачать примерно 3,4 ГБ с Hugging Face; на диске может понадобиться около 7 ГБ для кэша и архива. После скачивания распакуй ZIP, чтобы выбрать части в Forma. Для выбора места сохранения нужен совместимый браузер, например актуальный Chrome или Edge. Докачка после обрыва зависит от браузера и источника файлов.

Также можно скачать файлы отдельно из Hugging Face. Ход этого скачивания виден в загрузках браузера.

Модель Q4_K_M · 2,71 ГБ ↓ Для картинок (mmproj) · 676 МБ ↓

Файл модели целиком подойдёт для других совместимых программ. Чтобы загрузить его в Forma, сначала раздели его на части не больше 2 ГиБ через llama-gguf-split. Для генерации только по тексту mmproj не нужен.

Доступ к Hugging Face зависит от твоей сети. Есть сторонний каталог Hologram ↗; его доступность и загрузка из РФ не проверены.

Свои файлы модели

Выбери один GGUF-файл до 2 ГиБ или все части модели одновременно. Большой файл сначала нужно разделить через llama-gguf-split. Для картинок добавь отдельный файл mmproj.

Файлы останутся на устройстве; после перезагрузки страницы их нужно выбрать снова. Движок и предпросмотр всё ещё загружаются с внешних CDN.
